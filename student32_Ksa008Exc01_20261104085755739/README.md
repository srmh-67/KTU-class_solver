# ROOMSCOUT

予約データのZIPから、指定した日時に空いている教室を検索する静的Webアプリです。

## 使い方

1. `index.html` をGitHubリポジトリの公開対象ブランチに置く
2. GitHubの **Settings > Pages** で、Branch を選び `/ (root)` を指定する
3. 公開されたページを開き、教室予約データのZIPをアップロードする
4. 利用日と勤務区分（A〜E）を指定して検索する
5. 選択中の勤務の一覧をCSVで保存するか、「印刷用ページ」を開く
6. 印刷用ページの「印刷する / PDFに保存」から、プリンターまたはPDFとして保存する
7. 「全勤務CSV」「全勤務を印刷」で、A〜E勤務を教室ごとの1つの表にまとめる

ZIP内の `.xlsx`、`.xls`、`.csv` を対象に、全シート・全ファイルを統合します。指定時間と予約時間が重なる教室は空き教室から除外します。データはサーバーへ送信せず、ブラウザ内で処理します。

勤務時間は次の固定区分です。

- A勤務: 09:00 - 10:40
- B勤務: 10:55 - 12:35
- C勤務: 13:20 - 15:00
- D勤務: 15:15 - 16:55
- E勤務: 17:10 - 18:50

## 注意

Excel/ZIPの読み込みに jsDelivr の `JSZip` と `SheetJS` CDNを使用しています。PDFはブラウザ標準の印刷機能で保存します。インターネット接続がある状態で利用してください。
